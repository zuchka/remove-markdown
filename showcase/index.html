Make it yours.
Ten options. Exactly the text you need.

      

        
Lists
Choose what leads each item.
listUnicodeChar applies when markers are stripped.

        
Links
Keep the label, the URL, or both.
A separator takes precedence over URL-only mode.

        
Images
Let the description tell the story.
Switch off to remove the image entirely.
useImgAltText

        
Markdown extensions
A few extra kinds of syntax.
Fences, strike markers, and setext headings. Table and task-list syntax may remain.

        
HTML
Keep selected tags as literal text.
Comma-separated names. Empty strips all tags.
htmlTagsToSkip

        
MDX
Start where the writing starts.
Supported imports at the start of the document only. Other MDX syntax is not evaluated.
stripMdxImports

        
Advanced Error handling
When an error is caught by the library, the default behavior logs it and returns the original input. Enable this to throw instead. It does not change successful output.
The library’s catch block does not cover every input/setup error. This playground catches worker errors in either mode.
